## Desafio Atual: Modularização

O objetivo deste desafio é deixar a classe `Main` limpa, criando métodos auxiliares para:
1. `cadastrarUsuario`: Receber a lista, criar o objeto e adicionar.
2. `listarUsuarios`: Percorrer a lista e exibir no terminal.
3. `removerUsuario`: Receber a posição e remover do `ArrayList`.

---

## Como Rodar o Projeto

1. Compile e execute a classe `Main.java`.
2. Certifique-se de que a classe `Usuarios.java` está na mesma pasta/projeto.
